# Device instructions for this project

Use Andromeda to carry out the user's requested work on the selected Android device.

1. Observe the screen or accessibility tree before choosing an action. Use the current screen dimensions and rotation for coordinates.
2. Carry out only the work the user authorized. Request explicit confirmation before sending messages, making purchases, moving money, deleting data, or changing account access.
3. Check the result of meaningful actions with a fresh observation. An accepted input does not prove that the task succeeded.
4. After a timeout, disconnect, rotation change, or unexpected screen, observe again before deciding whether to retry. Ask the user when the intended next action is unclear.
5. Stop when the requested result is verified or the user asks to stop. Report the result and any unfinished work.
